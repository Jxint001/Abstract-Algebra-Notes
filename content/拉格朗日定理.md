由[[陪集（Coset）]]大小相等，以及每个陪集其实是元素的等价类，我们知道：$G$ 可以被 $\sim$ **划分成大小相等的集合**，也就是说，$\exists \alpha_1, \alpha_2, \cdots, \alpha_n \in G$ $s.t.$ $G = \sqcup_{i=1}^n \alpha_i H$ ，并且也 $\exists \alpha_1, \alpha_2, \cdots, \alpha_n \in G$ $s.t.$ $G = \sqcup_{i=1}^n H \alpha_i$ ，并且 $|\alpha_i H| = |H \alpha_i| = |H|$.

在引入拉格朗日定理之前，先给出一个重要定义：

>[!definition] index （指数）
>$(G, \cdot)$ 是群，$H < G$，$H$ 关于 $G$ 的 index $= |\{\alpha H \mid \alpha \in G\}| = |\{H \alpha \mid \alpha \in G\}|$，也就是 $H$ 的陪集数目。
>$H < G$，$H$ 关于 $G$ 的 index 也记成 $[G : H]$ 或者 $|G| / |H|$.

>[!theorem] 拉格朗日定理
>$(G, \cdot)$ 是**有限群**，$H < G$，有
>- $|H| \mid |G|$,
>- $|G| = [G:H] |H|$.

定理的证明可以直接由 $G = \sqcup_{i=1}^n \alpha_i H$ 和陪集相等得到：$|G| = \sum_{i=1}^n |\alpha_i H| = n |H|$，其中 $n$ 就是 index。

>[!lemma] 拉格朗日定理推论
> $\forall \alpha \in G$, $o(\alpha) \mid |G|$ ，其中$o(\alpha)$ 是[[元素的阶（order）]]。
> 
> 这等价于 $\alpha^{|G|} = e$。

该推论是把拉格朗日定理应用在[[循环群]]中得到。

>[!proof] 
> $(G, \cdot)$ 是有限群，$\forall \alpha \in G$，$\langle\alpha\rangle < G$ 是有限循环群。
> 由拉格朗日定理，$|\alpha| \mid |G|$。有限循环群中 $|\langle\alpha\rangle| = o(\alpha)$，因此 $o(\alpha) \mid |G|$。$\blacksquare$.

以下是拉格朗日定理及其推论的一个应用：证明欧拉定理。

>[!theorem] 欧拉定理
>若 $(a, n) = 1$，则 $a^{\varphi(n)} \equiv 1 (\mod{n})$.
>其中 $\varphi(n) = \#\{a \mid (a, n) = 1, a\in [n]\}$ 是欧拉函数，表示 $1, 2, \cdots, n$ 中与 $n$ 互素的数的个数。

回顾 [[群（Group）简介]] 中的例子 $(\mathbb{Z}_n^*, \cdot)$，可以看出 $\varphi(n) = |\mathbb{Z}_n^*|$.

>[!proof] 用拉格朗日定理及其推论证明欧拉定理
>首先把欧拉定理翻译成群论语言：如果 $\overline{\alpha} \in \mathbb{Z}_n^*$，那么 $\alpha^{\varphi(n)} \equiv 1 (\mod{n})$.
>鉴于 $\alpha^{\varphi(n)}$ 的形式，我们考察 $o(\alpha)$ 的大小。由于 $\mathbb{Z}_n^*$ 是有限群，可以应用拉格朗日定理得到 $o(\alpha) \mid |\mathbb{Z}_n^*$，也就是 $o(\alpha) \mid \varphi(n)$.
>由[[元素的阶（order）]]的定义，$\overline{\alpha^{o(\alpha)}} = e = \bar{1}$，从而 $\overline{\alpha^{\varphi(n)}} = \bar{1}$. $\blacksquare$.
