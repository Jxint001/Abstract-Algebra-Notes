
定义商群之前，我们先给出商集的定义：

>[!definition] 商集
>给定群 $(G, \cdot)$，$N<G$，$G / N = \{ \alpha_{1}N, \alpha_{2}N, \cdots, \alpha_{n}N, \cdots \}$（也就是 $G$ 关于 $N$ 的左陪集的集合）称为商集。

我们想要在商集上定义一种二元运算，使得商集和这个二元运算能组成一个群。
最自然的定义是
$$
\alpha N \bullet \beta N \triangleq \alpha\beta N.
$$

但是这样的定义不一定总是良定义的。我们接下来考察何时以上定义是良定义的。

我们希望对于 $\alpha'$ $\sim$ $\alpha$，即 $\alpha' \in \alpha N$，$\beta'$ $\sim$ $\beta$，即 $\beta' \in \beta N$，有 $\alpha\beta N = \alpha' \beta' N$，即 $\alpha' \beta' \in \alpha \beta N$ （这是因为一个简单的结论： $\forall x, y \in G$, $xN = yN \iff x \in yN \iff y^{-1}x \in N$）.

定义 $\alpha H \beta = \{ \alpha h \beta \mid h \in H\}$，$\alpha N\beta N = \{ \alpha h\beta s \mid h, s\in N\}$.
于是
$$
\alpha'\beta'\in \alpha\beta N \iff \alpha N\beta N \subset \alpha\beta N \text{(由$\alpha', \beta'$的任意性)}
\iff N \beta N \subset \beta N
$$
$$
\iff \beta^{-1} N \beta N \subset N
\iff \beta^{-1} N \beta \subset N
\iff N \subset \beta N\beta^{-1}.
$$
由 $\beta$ 的任意性，$N \subset \beta^{-1} N \beta$，$\forall \beta \in G$. 

因此良定义 $\iff$ $N=\beta^{-1} N \beta$，$\forall \beta \in G$.
基于以上讨论，我们给出商群的定义。

>[!definition] 商群
>$(G, \cdot)$是群，$N<G$，当 $\beta^{-1} N \beta = N$，$\forall \beta \in G$，$(G / N, \bullet)$ 是群，称为商群。（验证是群很简单。）
>
>$N$ 定义为 $G$ 的正规子群，$N \trianglelefteq G$，即 $N\beta = \beta N$，$\forall \beta \in G$.

>[!comment]
>如果 $G$ 是 abel 群，那么 $\forall H < G$，$H \trianglelefteq G$.

商群是重要的结构，许多复杂群都可以通过商群获得。
